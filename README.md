# Аргази · На судака

Русскоязычное приложение для планирования выхода с лодкой и эхолотом на Аргазинское водохранилище вечером 19 и утром 20 сентября 2026 года, со стороны Байрамгулово.

Сайт: https://ArtemiiPihalych.github.io/argazi-zander/

## Возможности

- Четыре авторских района поиска около островов, тактика для вечера и утра.
- Интерактивная карта OpenStreetMap, спутниковый слой Esri, локальный контур берега.
- Почасовая погода, переключение давления у поверхности / MSL, тренд, видимость и туман.
- Обновление Open-Meteo с сохранением исходного снимка при ошибке.
- Экспорт районов в GPX без навигационного маршрута.
- Локальный журнал глубин, импорт CSV/GeoJSON, экспорт GeoJSON. Данные пользователя не отправляются на сервер.
- Автономное сохранение интерфейса, плана и контура берега после первого открытия на GitHub Pages. Онлайн-тайлы не загружаются массово и не кэшируются приложением.

## Существенное ограничение

**Проверенная батиметрия не получена.** Найденные подробные карты MapFish и «Карта РУ Рыбалка» требуют платного доступа. Изобаты не выдумывались. На основной карте видны берега и острова, а круги — гипотезы для разведки эхолотом, не доказанные стоянки судака. Глубины в карточках — начальные диапазоны поиска, не промеры. Для полноценного слоя глубин нужны собственные или лицензированные данные.

Центры районов проверены на попадание в полигон воды OSM. Радиусы могут пересекать берег. Расстояния — по прямой от центра села, а не от слипа и не по безопасному пути на воде. GPX не предназначен для автоматического следования.

## Источники

- Open-Meteo Best Match, снимок получен 19.09.2026 08:37 UTC+5. Запрос 55.40 / 60.42; ячейка ответа 55.4375 / 60.4375, 271 м. [Документация](https://open-meteo.com/en/docs), CC BY 4.0.
- Независимая проверка: GFS через Open-Meteo; MET Norway Locationforecast, обновлён 19.09.2026 01:17:10 UTC, CC BY 4.0. Снимки — `dist/data/`.
- [OpenStreetMap, водохранилище relation 172936](https://www.openstreetmap.org/relation/172936), ODbL 1.0; геометрия берега `dist/data/shoreline.geojson`. Это географический контур, не глубины.
- Острова: [Липовый](https://www.openstreetmap.org/way/205958919), [Вишнёвый](https://www.openstreetmap.org/way/232726353), [Свинячий](https://www.openstreetmap.org/way/37633249).
- [MapFish](https://mapfish.ru/region/125), [Карта РУ Рыбалка](https://rybalka.mobilekarta.ru/ru/catalog/mapgallerylibrary/buy-depth-maps/dm_argazinskoe_01/) — внешние издатели карт глубин, их закрытые данные в проект не включены.
- [Horký et al., 2008](https://link.springer.com/article/10.1007/s10750-008-9503-0), [Poulet et al., 2005](https://doi.org/10.1007/s10750-004-6823-6), [Westrelin et al., 2022](https://onlinelibrary.wiley.com/doi/abs/10.1111/eff.12619) — основания поисковой тактики; исследования других водоёмов, а не прогноз клёва Аргази.
- [Правила Росрыболовства](https://fish.gov.ru/wp-content/uploads/2024/11/pravila_rybolovstva_dlya_zapadno_sibirskogo_rybohozyajstvennogo_bassejna.pdf), п. 15.2 и 36.1; сверка с [редакцией 08.09.2026](https://base.garant.ru/400453923/53f89421bbdaf741eb2d1ecc4ddb4c33/): судак от 35 см, группа видов суммарно 5 кг/сутки/человек. Границы охранной зоны плотины не установлены этим проектом.

## Разработка и публикация

Без сборки и установки зависимостей. Node.js нужен только для локального сервера и проверок:

```sh
npm start
npm run check
npm test
```

GitHub Pages публикует корень ветки `codex/pages`, полученной из каталога `dist`:

```sh
git subtree split --prefix dist -b codex/pages
git push origin codex/pages
```

При последующих обновлениях можно получить хеш `git subtree split --prefix dist` и отправить этот хеш в `refs/heads/codex/pages` (без force). Исходная ветка — `codex/argazi-planner`.

Leaflet 1.9.4 сохранён локально вместе с лицензией BSD-2-Clause. Данные третьих сторон сохраняют собственные лицензии. В приложении нет токенов, серверной базы и аналитики. Встроенные инструменты WebMCP доступны только в поддерживающем браузере и не требуются пользователю.
